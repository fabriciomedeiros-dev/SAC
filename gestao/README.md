# Gestão do Projeto SAC

Esta pasta concentra o acompanhamento do projeto sem substituir a documentação funcional publicada em `site/docs`.

## Arquivos

- `projeto.md`: estado atual e referências de fonte.
- `decisoes.md`: decisões registradas e decisões ainda necessárias.
- `tarefas.md`: pendências de planejamento e governança.
- `historico.md`: marcos já documentados no repositório.

## Fonte de verdade

As regras funcionais, os fluxos e as telas permanecem em `site/docs`. Este acompanhamento registra apenas informações de gestão extraídas desses documentos.
