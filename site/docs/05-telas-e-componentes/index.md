# Telas e Componentes

:::caution Ainda não iniciado
Esta seção depende dos [Fluxos de Navegação](../04-fluxos-de-navegacao/01-operador-de-triagem.md) estarem fechados por persona. Cada tela terá sua própria página aqui, descrevendo objetivo, componentes visíveis, ações disponíveis e regras de exibição condicional — sem entrar em detalhamento de codificação.
:::

## Modelo de página de tela (a ser usado quando iniciarmos)

- **Objetivo da tela**
- **Persona(s) com acesso**
- **Componentes** (listas, filtros, cards, formulários, botões de ação)
- **Regras de exibição condicional** (o que muda conforme estado do chamado ou permissão do usuário)
- **Ações e para onde levam** (navegação de saída)
